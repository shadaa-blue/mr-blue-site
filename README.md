# MR.BLUE // Classified Terminal

A real-time, classified-style web terminal built with **HTML, CSS, JavaScript**, and **Firebase Realtime Database** for live messaging, surveillance roleplay, and interactive room control.

## Key Features
* **Real-Time Messaging & Sync:** Live chat synchronization backed by Firebase Realtime Database with auto-burn message timers and room lock support.
* **Voice Synthesizer (TTS):** Multiple voice profiles (`deep`, `urgent`, `normal`), incoming message auto-read, and quick silence controls.
* **Autonomous NPC Dialogues:** Automated turn-based character conversations (`KAIROX` and `NOCTIS`) with distinct voices and typewriter text rendering.
* **Clearance & Terminal Commands:** Standard operator commands (`/scan`, `/ping`, `/status`, `/whoami`) plus `ARCHITECT // Ω` commands (`/npc`, `/probe`, `/stealth`, `/export`, `/intercept`, `/dossier`, `/fake-error`, `/threat`, `/purge`, `/selfdestruct`).
* **Classified Intel & Themes:** Secret `INTEL` dossier modal, customizable color themes (`blue`, `green`, `red`), and stealth shadow mode.

## Tech Stack
* Frontend: HTML5, CSS3, Vanilla JavaScript
* Backend / Realtime Sync: Firebase Realtime Database
* Speech & Audio: Web Speech API (`speechSynthesis`) & Web Audio API
